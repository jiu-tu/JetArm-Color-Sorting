# JetArm Color Sorting

基于深度相机的 JetArm 六轴机械臂 **颜色分拣与定位夹取系统**（课程设计项目）。

| 平台 | 视觉 | 分拣 | 状态 |
| --- | --- | --- | --- |
| OrangePi AI Pro（昇腾）· ROS2 Humble | Orbbec Gemini 深度相机 · OpenCV | 免训练 LAB 颜色阈值分割 | ✅ 两项功能验收通过 |

通过 **「视觉检测 → 深度反投影 → 手眼矩阵变换 → 逆运动学求解 → 舵机控制」** 完整闭环，实现机械臂对正前方积木的定位夹取与按颜色分拣。

---

## 功能特性

- **功能一（mode=right）**：识别机械臂正前方区域任意颜色物块，夹取后放置到**机械臂右侧指定区**（固定关节角序列，不依赖色标标定）。
- **功能二（mode=color）**：识别正前方红 / 绿 / 蓝三色积木，放置到**左侧对应颜色的色标区**；启动时自动扫描色标板完成放置点标定。
- **进阶功能**：三维形状分拣（圆柱 / 长方体轮廓圆度分类，`shape_sort_grab.py`）。
- **悬停标定模式（-p hover:=true）**：检测到目标后仅悬停于其上方 6cm、不闭爪，保存截图并打印期望位姿与实际末端位姿——用于量化坐标误差来源的调试工具。

**功能一验收（mode=right，三色连续运行）**

| 颜色 | 实测距离 | 放置结果 |
| --- | --- | --- |

| 蓝 | 0.272 m | 右侧指定区 ✅ |

**悬停标定五轮收敛（误差 5~6cm → <1cm，详见 docs/CHANGELOG.md）**

| 轮次 | 期望位姿 (x,y,z) | 实测反馈 | 补偿动作 |
| --- | --- | --- | --- |
| ① | (0.282, 0.128, 0.07) | 偏远 5~6cm、偏左 2~3cm | x−0.030, y−0.025 |
| ② | (0.128, 0.07, −0.012) | 姿势异常 | 回中修复 |
| ③ | (0.127, 0.048, −0.012) | 偏近 3cm | x 回 0 |

| ⑤ | (0.185, 0.029, 0.022) | 期望与实际一致 | 确认偏差在反投影，逐色补偿 |

## 技术栈

- **系统**：Ubuntu 22.04（aarch64）、ROS2 Humble、Python 3.10
- **视觉**：OpenCV（LAB 色彩空间阈值分割，免训练）、深度相机反投影（pinhole 内参 K）
- **机器人**：JetArm 六轴机械臂（总线舵机）、正/逆运动学服务、手眼标定矩阵
- **调试**：悬停标定模式、逐色三轴补偿、14 轮补丁迭代（见 `patches/`）

## 快速开始

```bash
# 1. 工作空间编译
colcon build --packages-select example

# 2. 功能二：颜色分拣（左侧色标区）
ros2 run example sort_grab --ros-args -p mode:=color

# 3. 功能一：右侧指定区
ros2 run example sort_grab --ros-args -p mode:=right

# 4. 悬停标定（调试工具）
ros2 run example sort_grab --ros-args -p hover:=true
```
